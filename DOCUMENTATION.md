# 1. Project Overview

- **Project Name:** `varad-water-solutions`
- **Purpose:** A high-performance commercial, industrial, and domestic water purification marketing and specification website for **Varad Water Solutions**, an engineering enterprise based in Solapur, Maharashtra, India.
- **Application Architecture:** Client-side Single Page Application (SPA) rendered in the browser. Zero server-side runtime required.
- **Tech Stack Breakdown:**
  - **Framework & Runtime:** React `^19.2.8` (`react`, `react-dom`) with modern Functional Components and Hooks.
  - **Build Tooling:** Vite `^6.2.0` with `@vitejs/plugin-react` `^4.3.4`. Fast HMR (Hot Module Replacement) and optimized Rollup production bundling.
  - **Language:** JavaScript (ES Modules, JSX). *Note: TypeScript is NOT used in the active source code; only dev-type declarations exist in `devDependencies`.*
  - **CSS & Styling Approach:** 
    - Tailwind CSS `^3.4.19` with PostCSS `^8.5.28` and Autoprefixer `^10.6.1`.
    - Custom theme extension and color tokens defined in `tailwind.config.js`.
    - Root CSS custom variables (`:root`) and scrollbar utilities defined in `src/index.css`.
  - **Animation Systems:**
    - **GSAP (GreenSock)** `^3.15.0` with `ScrollTrigger` plugin for viewport scroll reveals and progressive conduit drawing (`src/animations/animations.js`, `src/components/WaterJourney.jsx`).
    - **Framer Motion** `^13.4.1` for route-level page transitions (`pageVariants`) and Hero text masked-line entrance animations (`src/components/Hero.jsx`).
    - **Custom Hardware-Accelerated 2D Canvas Engine:** Native HTML5 `<canvas>` liquid particle simulation with sinusoidal fluid drift, specular droplet reflections, and desktop cursor repulsion (`src/components/ParticleBackground.jsx`).
    - *(Note: `@tsparticles/engine`, `@tsparticles/react`, and `@tsparticles/slim` `^4.4.0` exist in `package.json` as legacy dependencies, but the live particle system is powered by the 100% reliable custom Canvas in `ParticleBackground.jsx` to prevent React 19 StrictMode lifecycle conflicts).*
  - **Icon Library:** Lucide React `^1.47.0` (`lucide-react`). SVG icons imported on-demand as React components.
  - **Routing Library:** React Router DOM `^7.18.4` (`react-router-dom`) utilizing `BrowserRouter`, `Routes`, `Route`, `NavLink`, `Link`, and `useLocation`.
  - **Chart / Visualization:** Custom SVG vector schematics and Tailwind-styled HTML canvases (no third-party heavy charting libraries).
  - **Typography & Font System:** Google Fonts **Inter** (weights 300 to 800) preconnected in `index.html`, with native OS font stack fallbacks configured in `tailwind.config.js`.
  - **Asset Serving:** Static images and vector icons stored in `public/` and served at root path (e.g. `/images/...`, `/favicon.svg`).
  - **Deployment Model:** Builds to static HTML/CSS/JS in `dist/`. Can be hosted on any static hosting platform (Vercel, Netlify, Cloudflare Pages, GitHub Pages, AWS S3/CloudFront, or traditional Apache/Nginx).

### Folder Responsibilities:
- **`src/data/`**: **EDIT HERE MOST OFTEN.** Contains all business copy, phone numbers, prices, product descriptions, FAQs, and project references. Pure JavaScript objects/arrays.
- **`src/components/`**: Reusable visual blocks. Edit here when you need to change layout, add new HTML tags to cards, or adjust component-specific logic.

- **`src/animations/`**: GSAP ScrollTrigger configuration and Framer Motion variants. **DO NOT edit unless modifying scroll animation physics.**
- **`public/`**: Static files. Place new product photos, logos, or documents here.

# 12. How to Modify Animations

### 1. Make Water Particles Slower or Faster
1. Open `src/components/ParticleBackground.jsx`.
2. Locate lines 69–70:
   ```javascript
   vx: Math.random() * 0.35 + 0.18, // rightward drift
   vy: -(Math.random() * 0.32 + 0.16), // upward drift
   ```
3. **To make 50% slower:** Multiply values by `0.5`:
   ```javascript
   vx: (Math.random() * 0.35 + 0.18) * 0.5,
   vy: -(Math.random() * 0.32 + 0.16) * 0.5,
   ```

### 2. Increase or Decrease Particle Density
1. Open `src/components/ParticleBackground.jsx`.
2. Locate line 40:
   ```javascript
   const particleCount = prefersReducedMotion ? 12 : isMobile ? 18 : isTablet ? 30 : 48;
   ```
3. Change `48` to `70` for denser particles on desktop, or `25` for fewer particles.

### 3. Make Scroll Reveal Animations Snappier
1. Open `src/animations/animations.js`.
2. Locate line 37:
   ```javascript
   duration: 0.85,
   ```
3. Change to `0.5` for a faster, snappier reveal.

### 4. Disable Desktop Cursor Aura
If you want to turn off the cursor aura completely:
1. Open `src/App.jsx`.
2. Comment out or remove line 86:
   ```jsx
   {/* <CursorAura /> */}
   ```

# 16. Forms and User Interactions

### 1. Contact & Quotation Form (`ContactForm.jsx`)
- **State Fields:** `name`, `phone`, `requirement`, `message`.
- **Validation:** Ensures `name` is non-empty and `phone` contains 8–15 valid phone digits.
- **URL Parameter Pre-fill:** Automatically selects the `requirement` dropdown if user arrives via `/contact?model=100+LPH+RO+Plant` or `/contact?service=AMC`.
- **Submission Behavior:**
  - Client-side confirmation screen showing registrant's name.
  - Generates a **"Forward Directly to WhatsApp"** button formatted with encodeURIComponent:
    `wa.me/918657422232?text=*New Water Requirement Inquiry*...`

### 2. Sizing Calculator (`Products.jsx`)
- **State:** `occupancy` (`'small'`, `'medium'`, `'large'`, `'industrial'`).
- **Behavior:** Clicking a facility size pill dynamically highlights the recommended plant:
  - Small (10–50 occupants) → 100 LPH RO Plant
  - Medium (50–150 occupants) → 250 LPH RO Plant
  - Large / Industrial (150+ occupants) → 500 LPH Industrial Skid

### 3. Product Category Filter (`Products.jsx`)
- **State:** `selectedCategory` (`'All'`, `'Commercial'`, `'Industrial'`, `'Water Softening'`, `'Domestic'`).
- **Behavior:** Dynamically filters `productsData` and updates count text:
  - e.g. `"Showing 10 Domestic Systems"` or `"Showing 14 Systems"`.

### 4. Product Details Modal (`Home.jsx` & `Products.jsx`)
- **State:** `selectedProductForModal` (object or `null`).
- **Behavior:** Clicking "View Details" on any product card opens a backdrop-blurred modal showing the full product image, complete key specifications breakdown, recommended deployment tags, and a "Request Quotation" button that passes the model name to `/contact`.

- **Solution:** Node.js is not in your current shell's PATH. Run:

- **Cause:** Browser cache or React hot reload lag.
- **Solution:** Hard-refresh browser (`Ctrl + F5` or `Cmd + Shift + R`). If issue persists, restart the dev server.

### 3. Image Shows Broken Icon
- **Cause:** File path typo or missing file in `public/`.
- **Check:** Ensure the image exists in `public/images/...`. In your code, do **NOT** include `public` in the path:
  -  **CORRECT:** `image: "/images/products/domestic/p90-basic.webp"`
  - ❌ **INCORRECT:** `image: "/public/images/products/domestic/p90-basic.webp"`

### 4. Build Fails (`npm run build`)
- **Check:** Run `npm run build` in the terminal to inspect the specific file and line number causing the syntax or import error.
